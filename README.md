# 애플리케이션 프레임워크

## 수업계획서

| 학습목표                      | 1. Spring Boot의 기본 개념과 Spring Framework와의 차이점을 이해한다.<br/>2. Spring Boot를 이용한 향상된 웹 애플리케이션 개발 기법을 학습한다.<br/>3. 학습한 이론을 바탕으로 실제 웹 애플리케이션을 구현하여 실무 구현 능력을 배양한다.                                                                                                                                                                                                                                             |
| ----------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 학습방법                      | - 이론강의: 스프링부트 및 웹 표준 프로토콜 관련 이론과 기법 강의<br/>- 기타(시범과 실연): 강의를 통해 학습한 내용을 학생들이 직접 따라서 구현하고 실행함<br/>- 실습: 강의를 통해 얻어진 지식과 경험을 이용하여 주어진 문제를 해결                                                                                                                                                                                                                                                  |
| 평가방법                      | 출석: 20%, 평가(평소): 80%(과제 30%, 중간고사 25%, 기말고사 25%)                                                                                                                                                                                                                                                                                                                                                                                                                   |
| 토론,발표,시험등<br/>상세내역 | - 과제 : 주어진 문제를 해결하는 프로그램을 작성<br/>- 시험 : 이론 또는 프로그램 작성에 필요한 세부 기법을 묻는 질문에 답하는 문제                                                                                                                                                                                                                                                                                                                                                  |
| 과제등 상세내역               | - 각 차시 마다 실습한 결과물을 7주차, 14주차에 과제물로 제출한다                                                                                                                                                                                                                                                                                                                                                                                                                   |
| 수업매체 상세내역             | - 매주 수업시간 전에 E-클래스를 통해 제공된 강의자료를 중심으로 강의가 진행됨<br/>- 참고문헌:<br/>1.스프링 부트 4 개발자가 되기 + AI: 자바 편, 신선영, 골든래빗(주), 2026<br/>2.SpringBoot 공식 사이트에서 온라인으로 제공되는 참고자료를 통해 SpringBoot에 대한 추가적인 자료를 얻을 수 있음<br/>3.MDN Web Docs에서 온라인으로 제공되는 참고자료를 통해 웹 표준 및 브라우저 기술에 대한 추가적인 자료를 얻을 수 있음<br/>4.무료 온라인 강좌를 이용해 부족한 부분을 보충할 수 있음 |
